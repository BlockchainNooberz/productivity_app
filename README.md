# Productivity App ⚡📋

> AI-powered personal and team productivity suite

A full-featured productivity application with intelligent task management, project tracking, habit systems, and AI-assisted planning. Built to replace fragmented tools (Notion + Todoist + Calendar + AI assistant) with a single unified workspace.

## Features
- ✅ **Smart Task Manager** — AI-prioritized task lists with context-aware scheduling and deadline tracking
- 📁 **Project Workspace** — multi-project views with Kanban, list, and timeline layouts
- 🔁 **Habit Tracker** — streak tracking, accountability tools, and behavioral analytics
- 🤖 **AI Daily Planner** — generates optimized daily schedules based on tasks, energy patterns, and priorities
- 📊 **Productivity Analytics** — time tracking, focus metrics, and weekly performance reports
- 🔔 **Smart Notifications** — context-aware reminders that adapt to your workflow patterns
- 🗓️ **Calendar Integration** — two-way sync with Google Calendar and Outlook

## Tech Stack
- **Backend:** Python
- **AI:** LLM-powered task prioritization, planning, and summarization
- **Integrations:** Google Calendar, Gmail, Slack, Notion APIs
- **Database:** SQLite (local) / PostgreSQL (cloud)

## Getting Started
```bash
git clone https://github.com/BlockchainNooberz/productivity_app
cd productivity_app
pip install -r requirements.txt
python app.py
```
